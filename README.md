# FactWise AG Grid Dashboard

React + AG Grid client-side employee dashboard using the supplied 20-row assessment dataset.

## Features
- Client-side AG Grid
- Search
- Department filtering
- Active-only filtering
- Column sorting/filtering/resizing
- Pagination
- CSV export
- Stable row IDs
- KPI cards
- Reusable components
- Clean production-style structure

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```
